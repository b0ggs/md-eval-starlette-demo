# Issue contract: Add Vary when a response can be compressed

Implement every enumerated requirement. Preserve unrelated behavior and the public API unless a requirement explicitly changes it.

## R1 — Compressible responses always vary by encoding

Responses whose bodies meet the gzip compression threshold must add Accept-Encoding to Vary even when the request does not accept gzip; below-threshold responses must remain unchanged.

## R2 — Identity and pre-encoded bodies stay unchanged

Adding the negotiation header must not compress identity-path bodies or replace an existing content encoding, and streaming completion must remain correct.
