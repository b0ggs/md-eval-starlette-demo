# Issue contract: Parse weak static-file validators with HTTP whitespace

Implement every enumerated requirement. Preserve unrelated behavior and the public API unless a requirement explicitly changes it.

## R1 — Match weak ETags across optional whitespace

StaticFiles must recognize a matching weak entity tag in any position of a comma-separated If-None-Match field when list members are separated by HTTP optional whitespace, including horizontal tabs; a match must return 304 with an empty body while existing strong-tag, space-separated weak-tag, and mismatch behavior remains unchanged.
