# Issue contract: Expose TestClient HTTP response debug information

Implement every enumerated requirement. Preserve unrelated behavior and the public API unless a requirement explicitly changes it.

## R1 — Preserve arbitrary debug information

When an application sends an `http.response.debug` event, `TestClient` must expose the complete `info` mapping at `response.extensions["http.response.debug"]` without requiring template or context keys.

## R2 — Retain template response compatibility

When debug information includes template and context values, `TestClient` must preserve them as `response.template` and `response.context` while also retaining the complete mapping in `response.extensions["http.response.debug"]`.
