# Issue contract: Track session access and modification

Implement every enumerated requirement. Preserve unrelated behavior and the public API unless a requirement explicitly changes it.

## R1 — Modification controls persistence

Session middleware must emit Set-Cookie only when session data is modified; reading an unchanged session must not rewrite the cookie.

## R2 — Access controls cache variation

Accessing session data must add Cookie to Vary while preserving any existing Vary values.
