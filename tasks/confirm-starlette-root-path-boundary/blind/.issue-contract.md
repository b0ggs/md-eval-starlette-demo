# Issue contract: Respect root-path segment boundaries during routing

Implement every enumerated requirement. Preserve unrelated behavior and the public API unless a requirement explicitly changes it.

## R1 — Remove only a complete root-path prefix

When deriving a route path, `get_route_path()` must remove `scope["root_path"]` only when it matches a complete leading path segment or the entire path; a mere character-prefix match must leave `scope["path"]` unchanged.

## R2 — Preserve routes that share the root-path text prefix

With an application root path such as `/root`, routing must still match an application route whose first segment only begins with the same text, such as `/root-queue/path`.
