# Issue contract: Expose request and lifespan state as a mapping

Implement every enumerated requirement. Preserve unrelated behavior and the public API unless a requirement explicitly changes it.

State must support keyed get, set, delete, iteration, and length while retaining its existing attribute access behavior.

## R2 — Request state accepts typed mappings

HTTP connections and requests must expose lifespan-provided mapping state without discarding its mapping type or shared values.
