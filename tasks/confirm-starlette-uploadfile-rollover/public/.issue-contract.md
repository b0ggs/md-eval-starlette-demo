# Issue contract: Run UploadFile operations in a thread before future rollover

Implement every enumerated requirement. Preserve unrelated behavior and the public API unless a requirement explicitly changes it.

## R1 — Anticipate spooled-file rollover

UploadFile.write() must use the thread pool when the pending write will roll a spooled temporary file to disk, while retaining the in-memory fast path for writes that remain below the spool limit.
