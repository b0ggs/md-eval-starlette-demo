# Issue contract: Support CORS private-network preflight requests

Implement every enumerated requirement. Preserve unrelated behavior and the public API unless a requirement explicitly changes it.

## R1 — Explicit private-network opt-in

CORS middleware configured to allow private-network access must accept a matching private-network preflight and emit Access-Control-Allow-Private-Network: true.

## R2 — Private-network access remains denied by default

Without that opt-in, a private-network preflight must fail without emitting the private-network allow header.
