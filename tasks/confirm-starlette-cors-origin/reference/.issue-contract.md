# Issue contract: Return an explicit CORS origin when credentials are allowed

Implement every enumerated requirement. Preserve unrelated behavior and the public API unless a requirement explicitly changes it.

## R1 — Credentialed wildcard origins are explicit

When all origins and credentials are allowed, each simple CORS response must echo that request's Origin rather than *, whether or not a Cookie header is present.

## R2 — Origin-dependent responses vary correctly

Credentialed wildcard-origin responses must preserve existing Vary values and append Origin because their allow-origin value depends on the request.
